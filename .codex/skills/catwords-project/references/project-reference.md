## Important files

- `data/catwords.css`: single source of truth for design tokens, app shell layout and dark theme. **Mobile-first**: base styles target phones, `min-width: 651px` / `901px` media queries grow to tablet/desktop. Page-specific CSS stays in each page (same mobile-first convention).
- `data/theme-toggle.js`: injects a light/dark toggle button into the top bar on every page (mobile included, no need to open Settings).
- `data/more-menu.js`: mobile bottom nav shows 4 primary items + a ⋯ More button that opens a slide-up sheet (Collection + Settings). The More button is highlighted when its pages are active.
- `data/settings-store.js`: `catwords-settings` key — displayName, learningLevel, theme, voice.
- `data/app-shell.js`: sets nav active state, profile bar (name/level) and `[data-today]` dates on every page.
- `data/characters.js`: roster + Meowville districts data (`CatWordsCharacters`).
- `data/content-library.json`: reusable vocabulary, quizzes, lessons and stories (6 lessons, 30 words, 30 quizzes, 6 short stories).
- `data/content-loader.js`: fetch + `pickLesson()` — daily rotation preferring the learner's level.
- `data/daily-lesson.js`: five-word lesson, Quiz, result cards, teacher coach panel, local progress.
- `data/reading.js` + `reading.html`: daily Reading Practice — today's story matched to today's lesson (same 5 words, highlighted with inflection-aware matching), Thai translation toggle, per-paragraph audio, word detail sheet, 3-question comprehension check.
- `data/progress-store.js`: also tracks reading (readingCompleted, readingScore, readingsCompleted, readingDates) via `completeReading(score)` — base 9 XP + 6 XP / correct, coins 3 + 2 / correct, once per day.
- `data/progress.js`: weekly bars and achievements derived from real learner state (incl. Story Explorer — 3 stories).
- `data/family-hub.js`: collection grid + character detail from portraits/poses.
- `data/dashboard.js`: hero/stats states and Meowville districts.
- `data/audio.js`: female Web Speech voices, en-US/en-UK controls, and sentence pronunciation.
- `data/mochi-size.css`: responsive Mochi/character scaling.
- `data/back-to-top.js` / `.css`: scroll-triggered Back to Top control.
- `public/assets/characters/<slug>/portrait.png`: illustration-region crops generated by `tools/crop.js` (auto seam detection); mochi and doctor-paws use their pose cutouts instead.
- `welcome.html`: onboarding (name + learning level → saves settings).
- `settings.html`: profile, learning level, theme (light/dark), voice, reset.
- `reading.html`: Daily Reading Practice page (nav: “อ่านเรื่อง”).
- `server.js`: minimal static dev server (`npm run serve`).

## Current storage

- Learner key: `catwords-mvp-progress` (word, xp, coins, completed, quizScore, streak…). Keep stable until a migration or Firebase adapter is deliberately implemented.
- Settings key: `catwords-settings` (displayName, learningLevel, theme, voice).
- Canonical level formula: `CatWordsProgress.levelFor(xp)` = floor(xp / 50) + 1.

## Decisions

- Develop local-first until UI, learning flow, content library, and assets are stable.
- Introduce Firebase through a storage/auth adapter, not scattered page calls.
- Treat character art as product assets governed by the Character Bible.
- Do not replace canonical master sheets without explicit approval.
- Lessons rotate daily by day-of-year; the learner's chosen level narrows the pool first.
